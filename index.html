감정은 평소의 안정적인 상태에서 유지되거나, 긴장과 고조로 이어지는 등 다양한 흐름으로 나타납니다. emora는 이러한 감정의 흐름을 네 가지 상태로 구분하고, 각기 다른 형태와 그라데이션으로 감정의 특징을 시각화해 한눈에 이해하도록 돕습니다.

평상시 기본적으로 나타나는 형태

특별한 감정 변화가 감지되지 않은 평상시 상태에서 기본 형태로 나타납니다. 이후 생체신호에서 평소와 다른 변화가 감지되면 현재 감정을 확인하고, 확인된 감정에 맞는 형태로 전환됩니다. 이를 통해 평상시 상태와 감정 변화가 나타나는 순간을 구분해 시각적으로 보여주며, 한눈에 파악하도록 돕습니다.

같은 감정이 다시 나타났을 때

같은 감정이 다시 나타날 때 S자 형태의 곡선이 반복적으로 이어집니다. 곡선이 서로 연결되며 자연스러운 그라데이션을 형성하고, 감정이 되풀이되는 흐름을 표현합니다. 이를 통해 같은 감정이 시간의 흐름 속에서 다시 나타나는 모습과 반복되는 패턴을 시각적으로 구체적이고 직관적으로 보여줍니다.

한 감정이 다른 감정으로 퍼질 때

하나의 감정이 다른 감정으로 퍼져 나갈 때 나타납니다. 원형의 형태를 유지하면서 바깥으로 확장되는 파동의 그라데이션으로 감정이 번져가는 흐름을 표현합니다. 이를 통해 하나의 감정에서 시작해 다른 감정으로 이어지는 변화 과정과 감정의 확장 범위를 시각적으로 더욱 구체적이고 직관적으로 보여줍니다.

감정이 갑자기 변화 되었을 때

감정이 급격하게 변화할 때 뾰족한 끝 처리와 원형이 결합된 형태로 나타납니다. 서로 다른 형태가 자연스럽게 이어지는 그라데이션으로 갑작스럽게 변화하는 감정의 흐름을 표현합니다. 이를 통해 순간적으로 달라지는 감정의 특성과 변화의 방향을 시각적으로 더욱 구체적이고 명확하며 직관적으로 보여줍니다.

emora는 생체 신호의 변화를 감지해 상태를 확인할 시점을 틈으로 제안합니다. 사용자는 알림을 계기로 자신의 몸과 마음의 변화를 차분하고 세심하게 살펴보며, 신체 반응과 감정의 흐름을 직접 확인하고 현재 상태를 조금 더 구체적으로 인식합니다.

복합 감정은 마음속에 머무르지 않고, 충동적인 소비나 회피, 반응으로 이어집니다. 충동의 종류와 정도는 감정과 상황에 따라 달라지며, 같은 행동도 서로 다른 감정에서 비롯될 수 있습니다. 행동만으로 원인을 단정하기보다, 감정이 충동 행동으로 이어지기 전 틈이 필요합니다.

분위기를 연출하며, 사용자의 감정과 충동 사이 ‘틈’의 색깔로 사용하였습니다.

CORE VALUE

CORE VALUE

CORE VALUE

나를 이해하기

emora는 하루의 감정과 충동을 기록합니다. 쌓인 기록으로 감정 흐름을 살펴보고, 나의 상태와 반복 패턴까지 돌아볼 수 있습니다.

CORE VALUE

서로의 감정을 나누고
공감으로 이어지는 연결

감정 기록을 친구와 공유하고, 좋아요와 응원을 통해 서로의 마음을 나눕니다. 따뜻한 공감과 격려를 주고받으며 정서적 연결을 이어갑니다.

BRAND IDENTITY

emora의 아이콘은 로고의 곡선적 형태를 기반으로 작업하여 시각적인 통일성을 줍니다.

바닥을 딛듯 퍼지는 터미널과 완만한 하단 곡선을 시그니처 요소로 삼아, 핵심 메뉴는 시그니처

아이콘으로, 반복되는 기능은 시스템 아이콘으로 구분해 일관된 시각 언어를 형성합니다.
